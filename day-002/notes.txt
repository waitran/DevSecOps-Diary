Процессы в Linux
Программа — файл на диске.
Процесс — программа, которая выполняется прямо сейчас.
У каждого процесса есть:
PID  — уникальный номер процесса
PPID — номер родительского процесса
UID  — пользователь, от имени которого работает процесс
Просмотр процессов
ps
Показывает снимок процессов в данный момент.
Посмотреть все процессы:
ps aux
a → процессы всех пользователей
u → показать владельца и детали
x → процессы без терминала (демоны)

Колонки:
USER   → владелец
PID    → ID процесса
%CPU   → нагрузка на процессор
%MEM   → нагрузка на память
RSS    → реальная память в КБ
STAT   → состояние процесса
COMMAND→ команда запуска

top / htop
Показывают процессы в реальном времени.

Состояния процессов (STAT)
R → Running     — выполняется
S → Sleeping    — спит, ждёт события
D → Disk sleep  — ждёт диск (проблема!)
T → Stopped     — остановлен
Z → Zombie      — завершён, но родитель не забрал код возврата

Управление процессами (сигналы)
kill
Отправляет сигнал процессу по PID.
По умолчанию отправляет SIGTERM (15) — вежливая просьба завершиться

kill -9 1234
Отправляет SIGKILL (9) — принудительное уничтожение ядром.

kill       → SIGTERM (15) → процесс может сохраниться и выйти
kill -9    → SIGKILL (9)  → ядро убивает немедленно

pgrep
Ищет процессы по имени и выводит PID.

Флаг -x — точное совпадение (exact match):

/dev/null
«Чёрная дыра» Linux. Всё, что туда попадает, исчезает.
