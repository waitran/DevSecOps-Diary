модель OSI - Open System Interconnection состоит из семи уровней, самые ключевые из них это L3,L4 и L7.

L1 - physical layer, на этом уровне представлены физические взаимодействия, то есть взаимодействие с физическими устройствами: кабелями, оборудованием и т.п.
L2 - data link layer, на этом уровне происходит передача данных непосредственно соедененными узлами о одной локальной сети. Отвечает за MAC-адреса, взаимодействие с комутаторами, хабами и т.п.
L3 - network layer, отвечает за передачу пакетов между разными сетями. Работает с логическими адресами
L4 - transport layer, отвечает за доставку данных от процесса к процессу на разных хостах.
L5 - session layer, отвечает за поддержание сессий между приложениями.
L6 - presentation layer, отвечает за формат данных: кодировка, шифровка, дешифрование, сжатие, преобразование кодировок
L7 - application layer, предоставляет сетевые услуги пользователю, непосредственно конечному приложению. Это то, с чем взаимодействует пользовватель или API

IP-адрес - это адрес здания, а порт это непосредственно квартира

важные порты:
22 - SSH (удаленный доступ)
53 - DNS (резолвинг имен)
80 - HTTP (интернет трафик без шифрования)
443 - HTTPS (веб-трафик с TLS шифрованием)
3306/5432 - MySQL / PostgreSQL (базы данных)
6443 - Kubernetes API Server
8080/8081 - альтернативные HTTP порты (часто испоьзуются в контейнерах)

DNS - Domain Name System - буквально телефонная книга, ya.ru → 77.88.55.88, 

nslookup - просто покажет IP
dig - показывает весь процесс и заголовки ответа

пример: dig +short ya.ru  # +short выдает только чистый IP

КОДЫ ОТВЕТОВ:
2XX - успех (200 OK, 201 Created)
3XX - перенаправление (301 Moved Permanently, 302 Found)
4XX - ошибка клиента (400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found)
5XX - ошибка сервера (500 Internal Server Error, 502 Bad Gateway, 503 Service Unvaliable)

firewall - межсетевой статус, который фильтрует сетевой трафик на основе некоторых правил

sudo ufw status              # Проверить статус
sudo ufw allow 22/tcp        # Разрешить входящий SSH (ВСЕГДА делай это первым!)
sudo ufw allow 80,443/tcp    # Разрешить веб-трафик
sudo ufw deny 3306           # Явно запретить доступ к БД извне
sudo ufw enable              # Включить фаервол (потребует подтверждения)
sudo ufw reset               # Сбросить все правила (если что-то сломал)

iptables — это низкоуровневый инструмент, на котором работает ufw.

ufw - uncomplicated firewall  Упрощает настройку сложного стандартного пакетного фильтра iptables или nftables, заменяя длинные команды понятным интерфейсом.

Главное правило безопасности - запретить все то, что явно не разрешено
